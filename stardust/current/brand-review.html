Tensions

T-scale

Type scale is ad-hoc (48 → 32 → 18.4 → 17.6 → 16.8 → 16 → 15.2 px, no consistent ratio). A replica keeps it as is; direct would need to decide whether a redesign adopts a modular scale.

T-logo-variants

No logo captured at all (no inline SVG, no logo image, no icon link, /favicon.ico unreachable). The header is two text links; the replica ships without a logo and without a favicon unless the owner provides them.

T-color-imbalance

#6a1b9a (primary), #5e35b1 (lede) and #00897b (secondary) appear as text only — never as a fill; #26c6da and #ec407a appear as borders only. In a replica these stay exactly where they are.

T-no-tokens

No CSS custom properties defined. The current site has no design-token layer; the Edge Delivery target introduces tokens in styles.css, which is a structural (not visual) change.

Fonts named, not loaded

'Poppins' and 'Playfair Display' are named in the stylesheet but no font files are served; the page renders in whatever system fonts the visitor's device has. The replica keeps the identical stacks so the rendering stays the same device-for-device.
