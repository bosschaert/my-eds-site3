## Delivery design notes (written before C-deliver, 2026-10-01)
- **Canvas model:** live `#canvas` = 1200 content + 76 padding, `margin: 10px auto` (≤750: `0 auto`, padding `0 20px 20px`). In EDS each of `header`, `main`, `footer` gets `max-width: 1200px; margin: 0 auto; padding: 0 76px; box-sizing: content-box`; the header carries the canvas top (10 + 76), the footer the bottom (76 + 10). `main { padding: 57px 76px }` (= live `#page`), grid wrapper `margin-top: -1.2%`.
- **Header block (template-slotted):** one authored `<ul>` rendered once; flex-column `order` swaps it between the mobile position (above the "Menu" link, `#mobileNav`) and the desktop position (`#topNav` under the logo) — no clone. Keep ids `header`, `logo`, `topNav`, `mobileNav`, `mobileMenuLink` so motion-observe pokes match; the toggle adds `menu-open` on `body` (observed). "Menu" text and the dotted `.page-divider` are block-owned (`@ew-exempt`). Try the brand as an authored `<h1><a href="/"><img></a></h1>` in `/nav`; if the pipeline drops the h1, fall back to a `.logo` div and record it. Header reservation: `--nav-height` per breakpoint plus `header:has(.header[data-block-status="loaded"]) { height: auto }`.
- **project-grid block (reconstructive):** one row per project — cell 1 picture, cell 2 `<p><a href="/slug/">Title</a></p><p>count</p>`. decorate() moves nodes into `a.project > div > .project-image / .project-item-count` + `.project-title` (EW6: unwrap the inner anchor after reading href). Masonry: cols = max(1, floor(W/300)), gutter = W/100, floored heights, shortest column, aspect from the img `width`/`height` attrs (else naturalWidth after load), relayout on load + resize; images `loading="eager"` like the source.
- **Footer block (template-slotted):** `/footer` sections: 1 newsletter (`h2` Subscribe, description `p`, footnote `p`), 2 legal `p`, 3 social link (Instagram). Block JS renders the email input + "Sign Up" button (`type="button"`, no-op until the owner names a provider — dynamics row 5) and the icon (`/icons/instagram.svg`, fill `#f26447`).
- **Images:** upload the captured `-500w` renditions (`stardust/current/assets/media/`) with `da-media-upload.mjs --scope index`; the logo (`stardust/prototypes/img/logov2.png`) with `--scope nav`. Fonts: `PTSerif-400.woff2`, `SourceSans3-var.woff2` → `/fonts`, declared in `styles/fonts.css`; favicon from `stardust/prototypes/assets/favicon.ico`.
- **Out-of-scope link targets** (`/about`, `/blog`, `/contact`, the 96 project paths): keep the captured root-relative hrefs in content; the redirects sheet (`/redirects.json`, D-site) sends each (slash and slashless form) to the same path on `https://www.thebeastisback.com` — E2's "scope extension → repoint", recorded in `direction.md` at D-site. `Shop` stays the external `http://store.thebeastisback.com/`.
- **Deviation (foundation):** the 96 project hrefs are authored slashless (`/slug`, not the captured `/slug/`) — `delivery-lint` flags the trailing slash as P1 (EDS 404s on `/x/`); the redirects sheet already covers both forms, so the target is unchanged.
- **Deviation (foundation):** the header keeps `#mobileNav` and `#mobileMenuLink` INSIDE `#header` (flex column, `order` per breakpoint) so one authored `<ul>` serves both positions; the single `<nav>` carries `id="topNav"` inside `#mobileNav > .wrapper`. Vertical flow is unchanged (measured header 323.4 at 1440, 231 at 360 — the live values). The active nav link is marked `aria-current="page"` (styled) instead of a `.active-link` class on the authored list.
- **Deviation (foundation):** the Instagram glyph is the authored `:instagram:` icon (`span.icon` → `/icons/instagram.svg`, fill baked as `#1f1f1f` — the live value measured on the page; the prototype's `var(--color-accent)` was a prototype defect — because an `<img>` SVG cannot take a CSS fill); the footer newsletter uses a `div.newsletter-form` (no `<form>`) and the pipeline reports tile images at their 500w rendition size (500×500 etc. — same aspect), which the masonry reads from `width`/`height`.
