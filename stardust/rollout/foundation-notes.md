# Foundation notes (C0) — for the cluster subagent

- Tokens (`styles/styles.css :root`, prototype verbatim): `--paper --parch --line --ink --ink-soft --taupe --leaf --leaf-dark --gold --nav-h --nm-radius --nm-focus --house-image-radius --frame-room-card-ratio --nm-preview-image-max --font-sans --font-serif --font-gujarati`, plus `--nav-height: 81px` (77px at `width <= 720px`). Every `var(--x)` a block uses must be in this list — add nothing per block; ask for a foundation change instead.
- Section scaffold: `main .section { margin: 0; padding: 0 }`; `main .section > div { max-width: 74rem; margin: 0 auto; padding: 0 7vw }` is the prototype's `.wrap`. Each block owns its own vertical padding and background. A full-bleed block overrides the column in its own CSS: `main .X-container > div { max-width: none; padding: 0 }` (the `-wrapper`/`-container` classes are section-level).
- Reset is global: `*, *::before, *::after { box-sizing: border-box }`, `* { margin: 0; padding: 0 }` — no boilerplate p/ul/h margins remain; blocks set their own. `img { display: block; max-width: 100%; height: auto }`. `a { color: inherit; text-decoration: none }`. `a[target="_blank"]:not(.button)::after` adds the " ↗" glyph.
- Type: body 17px/1.7 Inter (1.68 at `<= 720px`); `h1, h2, h3` Playfair 400 / 1.16; `h2 { font-size: clamp(2.2rem, 5vw, 3.6rem); margin: .25rem 0 1rem }`. The prototype's `.eyebrow` / `.lede` type roles are NOT in styles.css — port them inside the block that uses them (wrapper-descendant selectors, EW2).
- Buttons: the runtime buttonizes only `<strong><a>` / `<em><a>` / both (`a.button.primary` / `.secondary` / `.accent` inside `p.button-wrapper`). All three variants are ONE identical outline paint (`main a.button` = the prototype's `.btn`); `main p.button-wrapper { margin: 0 }`. A plain `<p><a>` stays a text link. Edit-mode repaint (`.prosemirror-editor …`) ships in styles.css.
- `.sr-only` is available for visually-hidden h1/h2.
- Fonts: `styles/fonts.css` is the Google css2 response verbatim (Inter 300–700, Playfair Display 400–900 + italic, Rasa), files in `fonts/gf/`. Loaded by `loadFonts()`; never link fonts in head.html; use `var(--font-sans)` / `var(--font-serif)` / `var(--font-gujarati)`.
- Header host: `header { position: sticky; top: 0; z-index: 20; height: var(--nav-height); background: var(--paper) }`. Block DOM inside `header .header`: `div.nmh-header > (div.nmh-home > p > a, div.nmh-title > p, button.nmh-menu-btn)`. Body-level chrome created by header.js: `div.nm-reading-progress > span` (z 9999), `div.nmh-overlay` (z 9998) + `nav.nmh-menu#nmh-drawer` (z 9999, holds the authored `<ul>`), `div.nm-legacy-bar` (z 50, fixed 1px line at top), `button.nm-top` (z 70). Do not emit `<header>` in any block (the host rule clamps it).
- Footer: `footer .footer > div.nmh-footer > ul` (flex, wraps at `<= 720px`); no host margin — the last section owns the gap above the footer (none in the prototype).
- Scroll behaviour (progress bar, back-to-top past 500px, drawer) lives in header.js; blocks add no scroll-state chrome.
- Chrome documents: `content/nav.html` (`/nav`), `content/footer.html` (`/footer`), both `Robots | noindex`; out-of-scope targets are absolute on `https://www.niravmanubhai.com`.
- Lint: `npm run lint:fix` then `npm run lint` must exit 0; stylelint rewrites `rgba()` to `rgb(… / n%)` and media queries to range notation — values stay exact.
